# [US-014] Avoid autoplay and automatic loading of videos and sounds

> **Epic:** BP2 (see [EPIC-BP2-conventions.md](EPIC-BP2-conventions.md))
> **Rule:** `AvoidMediaAutoplay`, "Éviter la lecture et le chargement automatique des vidéos et des sons", category `content`
> **Status:** DONE (automated gates passed, manual browser checks pending; see `docs/reviews/REVIEW-US-006-014.md`)

## 1. User Story Statement

**As an** eco-design auditor,
**I want** each page to report the videos and sounds that play or fully preload without user action,
**So that** visitors only download heavy media they actually choose to play.

## 2. Context & Detailed Description

### Elements checked

`<video>` and `<audio>` elements in the top-frame DOM, read at collection time.

### Offender

This was a product decision. An element is an **offender** when either:

1. it has the **`autoplay` attribute, whatever its value**. `autoplay` is a boolean attribute, so `autoplay="false"` still autoplays. This includes muted background videos; or
2. its **`preload` attribute is `auto` or empty** (`preload=""` means `auto`), case-insensitive.

An element **without** `autoplay` and with no `preload`, `preload="metadata"` or `preload="none"` is compliant. When `preload` is absent the browser default applies, usually `metadata`.

### Grade

These follow the request.

- **A:** no offender, or no `video` or `audio` element: "Aucune vidéo ni aucun son lancé ou préchargé automatiquement".
- **B:** exactly **1** offender.
- **C:** **more than 1** offender.

### Offender lines

- `Vidéo <display name> : lecture automatique` or `Son <display name> : préchargement complet (preload="auto")`.
- Both reasons appear when both apply, joined with " et ".
- The display name comes from `currentSrc`, else `src`, else the first `<source src>`, else "(sans source)".

## 3. Tech Stack Hints & Scope Constraints

- **In scope:** `video` and `audio` in the top-frame DOM; attribute-based detection.
- **Out of scope:**
  - embedded players in iframes (YouTube `autoplay=1`);
  - media created by scripts and not attached to the DOM (`new Audio()`);
  - autoplay started by script with `play()` while the element has no `autoplay` attribute;
  - the browser's autoplay policy (whether playback was actually allowed).
- **State:** synchronous.
- **Persistence:** stored with the page.

## 4. Acceptance Criteria (Gherkin Scenarios)

### Scenario 1: Happy path: media waits for the user
Given a `<video src="demo.mp4" controls preload="none">` and an `<audio src="podcast.mp3" controls>`
When the best practices are evaluated
Then the rule is graded "A"

### Scenario 2: One autoplay video gives B
Given a `<video src="hero.mp4" autoplay muted loop>`
When the best practices are evaluated
Then the rule is graded "B" with the line "Vidéo hero.mp4 : lecture automatique"

### Scenario 3: autoplay="false" still counts
Given a `<video src="intro.mp4" autoplay="false">`
When the best practices are evaluated
Then it is an offender with the reason "lecture automatique"

### Scenario 4: preload auto or empty
Given an `<audio src="jingle.mp3" preload="auto">` and a `<video src="clip.mp4" preload="">`
When the best practices are evaluated
Then the rule is graded "C"
And both are listed with "préchargement complet (preload=\"auto\")"

### Scenario 5: preload metadata or absent is compliant
Given a `<video src="a.mp4" preload="metadata">` and a `<video src="b.mp4">` without `preload` or `autoplay`
When the best practices are evaluated
Then neither is listed

### Scenario 6: Both reasons on one element
Given a `<video src="bg.mp4" autoplay preload="auto">`
When the best practices are evaluated
Then the line is "Vidéo bg.mp4 : lecture automatique et préchargement complet (preload=\"auto\")"
And it counts as one offender

### Scenario 7: Source from a source child
Given a `<video autoplay>` with a child `<source src="/media/teaser.webm">`
When the best practices are evaluated
Then the line names "teaser.webm"

### Scenario 8: Page without media
Given a page with no `video` or `audio` element
When the best practices are evaluated
Then the rule is graded "A" with the detail "Aucune vidéo ni aucun son lancé ou préchargé automatiquement"

## 5. Non-Functional Requirements (NFRs) & Constraints

- **Performance:** `collect()` handles 500 media elements in under 20 ms.
- **Self-contained collector:** it passes the registry serialisation test.
