# [US-006] Provide a textual alternative to multimedia content

> **Epic:** BP2 (see [EPIC-BP2-conventions.md](EPIC-BP2-conventions.md))
> **Rule:** `ProvideTextAlternatives`, "Fournir une alternative textuelle aux contenus multimédias", category `content`
> **Status:** DONE (automated gates passed, manual browser checks pending; see `docs/reviews/REVIEW-US-006-014.md`)

## 1. User Story Statement

**As an** eco-design and accessibility auditor,
**I want** each page to report images and videos that have no textual alternative, or an empty one,
**So that** content stays understandable without loading or seeing the media, and the site meets its accessibility obligations.

## 2. Context & Detailed Description

### Elements checked

`collect()` in the top frame inspects the following elements.

| Element | Valid textual alternative |
|---|---|
| `<img>`, including the `<img>` inside a `<picture>` | `alt` attribute, or `aria-label`, or `aria-labelledby` pointing to non-empty text |
| `<input type="image">` | same as `<img>` |
| `<area href>` | same as `<img>` |
| `<video>` | a `<track kind="captions">` or `<track kind="subtitles">` child, or `aria-label`, or `aria-labelledby` (non-empty), or `title` (non-empty) |

- `<picture>` and `<source>` carry no alternative themselves. The inner `<img>` is the one checked, and is counted once.
- `<video alt>` is not valid HTML, so videos use the alternatives listed above. This was a product decision.
- `<audio>` is out of scope: its alternative is a transcript, which cannot be detected reliably.

### Classification of each element

These are product decisions.

1. **Decorative, compliant.** The element has `role="presentation"`, `role="none"` or `aria-hidden="true"`. It needs no alternative.
2. **Tracking pixels, ignored.** Images whose natural size is at most 1 × 1 are not counted. This is a PO default: they are not multimedia content.
3. **Compliant.** A non-empty alternative, after trimming whitespace.
4. **Empty alternative, "to review" (B).**
   - Condition: `alt=""` or `alt` containing only whitespace, with no `aria-label` or `aria-labelledby`.
   - Line: "Alternative vide : à vérifier si l'image n'est pas décorative".
   - `alt=""` is the WCAG marking for decorative images, so this is a warning to review, not an error.
5. **Missing alternative (C).** `<img>`, `<input type="image">` or `<area>` with no `alt` attribute and no ARIA label; or a `<video>` with none of its alternatives.

### Grade

- **C:** at least one element with a missing alternative.
- **B:** none missing, but at least one empty alternative.
- **A:** otherwise, including a page without any of these elements: "Aucun contenu multimédia sans alternative textuelle".

### Offender lines

- **Images:** `<display name> : alternative absente` or `<display name> : alternative vide (à vérifier si l'image n'est pas décorative)`.
- **Videos:** `Vidéo <display name of src or first <source>> : ni sous-titres ni libellé`.
- Missing alternatives are listed first, then empty ones.

## 3. Tech Stack Hints & Scope Constraints

- **In scope:** the elements above, in the top-frame DOM at collection time.
- **Out of scope:**
  - `<audio>`;
  - inline `<svg>` and CSS background images;
  - `<object>` and `<embed>`;
  - checking the *quality* of the alternative text;
  - iframes.
- **State:** synchronous; no loading state.
- **Persistence:** the rule result is stored with the page, like the other rules.

## 4. Acceptance Criteria (Gherkin Scenarios)

### Scenario 1: Happy path: all images and videos have alternatives
Given a page with `<img src="logo.png" alt="Logo EcoInsights">` and a `<video>` with a `<track kind="captions">`
When the best practices are evaluated
Then the rule is graded "A"

### Scenario 2: Missing alt gives C
Given a page with `<img src="hero.jpg">` and no `alt`, `aria-label` or `aria-labelledby`
When the best practices are evaluated
Then the rule is graded "C"
And the line "hero.jpg : alternative absente" is listed

### Scenario 3: Empty alt gives B, to review
Given a page whose only flagged image is `<img src="separator.png" alt="">`
When the best practices are evaluated
Then the rule is graded "B"
And the line "separator.png : alternative vide (à vérifier si l'image n'est pas décorative)" is listed

### Scenario 4: C wins over B
Given a page with one image without `alt` and one image with `alt=""`
When the best practices are evaluated
Then the rule is graded "C"
And the missing alternative is listed before the empty one

### Scenario 5: Explicitly decorative images are compliant
Given `<img src="deco.png" alt="" role="presentation">` and `<img src="deco2.png" aria-hidden="true">` without `alt`
When the best practices are evaluated
Then neither image is listed and the rule is graded "A"

### Scenario 6: ARIA label is a valid alternative
Given `<img src="chart.png" aria-label="Évolution des émissions">` without `alt`
When the best practices are evaluated
Then the image is compliant

### Scenario 7: Picture element counted once, through its img
Given a `<picture>` with two `<source>` and an inner `<img alt="Photo">`
When the best practices are evaluated
Then exactly one element is checked and it is compliant

### Scenario 8: Video without captions or label
Given a `<video src="intro.mp4">` with no `<track>`, `aria-label`, `aria-labelledby` or `title`
When the best practices are evaluated
Then the rule is graded "C" with the line "Vidéo intro.mp4 : ni sous-titres ni libellé"

### Scenario 9: Tracking pixel is ignored
Given an `<img src="pixel.gif">` with natural size 1×1 and no `alt`
When the best practices are evaluated
Then it is not listed and does not affect the grade

### Scenario 10: Page without multimedia content
Given a page with no `img`, `picture`, `input[type=image]`, `area` or `video`
When the best practices are evaluated
Then the rule is graded "A" with the detail "Aucun contenu multimédia sans alternative textuelle"

### Scenario 11: aria-labelledby pointing to empty or missing text
Given `<img src="a.png" aria-labelledby="missing-id">` without `alt`, where no element has id "missing-id"
When the best practices are evaluated
Then the image is listed as "alternative absente"

## 5. Non-Functional Requirements (NFRs) & Constraints

- **Performance:** `collect()` handles 2 000 elements in under 50 ms in the page.
- **Self-contained collector:** it must pass the registry serialisation test (ARCH-DECISION-004).
- **Accessibility:** offender lines are plain text; the grade is never shown by colour alone (existing UI).
