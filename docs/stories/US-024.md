# [US-024] Externalise CSS and JavaScript

> **Epic:** BP3 (see [EPIC-BP3-conventions.md](EPIC-BP3-conventions.md))
> **Rule:** `ExternalizeCssJs`, "Externaliser les CSS et JavaScript", category `js`
> **Status:** DONE (automated gates passed, manual browser checks pending; see `docs/reviews/REVIEW-US-024-027.md`)

## 1. User Story Statement

**As an** eco-design auditor,
**I want** each page to report the CSS and JavaScript written inline in the HTML,
**So that** the site owner moves them to external files, which the browser caches and reuses across pages instead of downloading them again with every HTML page.

## 2. Context & Detailed Description

### Elements counted

These are owner decisions.

- **`<style>` elements** of the page.
- **Inline `<script>` elements:** `<script>` with **no `src` attribute** and a **JavaScript type**:
  - no `type` attribute, or an empty one;
  - `module`;
  - a JavaScript MIME type (`text/javascript`, `application/javascript`, `application/ecmascript`, `text/ecmascript`, `application/x-javascript`), case-insensitive, parameters ignored.
- **Not counted:**
  - `<script src>`, which is already external;
  - non-JavaScript scripts: `application/ld+json`, `application/json`, `importmap`, `speculationrules`, `text/template`, `text/x-template` and any other type;
  - `<style>` or `<script>` whose content is empty or whitespace only;
  - `style="…"` attributes and `on…=` event attributes (out of scope);
  - elements inside iframes or shadow roots.
- **Source: the DOM at collection time,** so elements added by scripts, for example CSS-in-JS `<style>` tags, are counted. This is a PO default: it works for single-page applications, where navigations load no new HTML document.

### Grade

These are owner decisions on the number **n** of counted elements.

- **A:** n ≤ 2.
  - n = 0: "Aucun CSS ni JavaScript en ligne".
  - Otherwise: "<n> bloc(s) CSS ou JavaScript en ligne".
- **B:** 3 ≤ n ≤ 5.
- **C:** n ≥ 6.
- **Detail for B and C:** "<n> blocs CSS ou JavaScript en ligne (<s> <style>, <j> <script>) : à externaliser dans des fichiers mis en cache".

### Offender lines

Lines are listed for B and C only.

- **Format:** `<tag> en ligne : <size in ko>`, for example `<script> en ligne : 12 ko` or `<style> en ligne : 0,4 ko`.
  - When the element has an `id`: `<script id="gtm"> en ligne : 12 ko`.
  - The size is the length of the text content in characters, shown with `formatKo`.
- **Order:** largest first, then document order.
- No file name, so no preview.

## 3. Tech Stack Hints & Scope Constraints

- **In scope:** a self-contained `collect()` returning `{ tag, id, size }` per counted element, and a pure `evaluate()`.
- **Out of scope:**
  - inline `style` attributes;
  - inline event handlers;
  - parsing the original HTML source;
  - shadow DOM;
  - judging whether a small inline critical CSS is legitimate.
- **State:** synchronous.
- **Persistence:** stored with the page.

## 4. Acceptance Criteria (Gherkin Scenarios)

### Scenario 1: Happy path, no inline code
Given the page has only `<link rel="stylesheet">` and `<script src>` elements
When the best practices are evaluated
Then the rule is graded "A" with the detail "Aucun CSS ni JavaScript en ligne"

### Scenario 2: Boundary, 2 blocks give A
Given the page has 1 `<style>` and 1 inline `<script>`
Then the rule is graded "A" with the detail "2 blocs CSS ou JavaScript en ligne"

### Scenario 3: Boundaries of B
Given the page has 3 counted elements
Then the rule is graded "B"
Given the page has 5 counted elements
Then the rule is graded "B"

### Scenario 4: Boundary, 6 blocks give C, with lines
Given the page has 2 `<style>` (1 000 and 400 characters) and 4 inline `<script>` (12 000, 300, 300 and 50 characters, the second one with id "gtm")
When the best practices are evaluated
Then the rule is graded "C" with the detail "6 blocs CSS ou JavaScript en ligne (2 <style>, 4 <script>) : à externaliser dans des fichiers mis en cache"
And the first line is "<script> en ligne : 12 ko"
And the two 300-character scripts are listed in document order

### Scenario 5: Non-JavaScript and external scripts are ignored
Given the page has a `<script type="application/ld+json">`, a `<script type="importmap">`, a `<script type="text/template">`, two `<script src="…">` and one `<script type="module">` with code
Then only the module script is counted

### Scenario 6: Empty blocks are ignored
Given the page has an empty `<style></style>` and a `<script>` containing only whitespace
Then neither is counted

### Scenario 7: Injected styles are counted
Given a script added 4 `<style>` elements with content to the document before collection
Then they are counted

### Scenario 8: Collector failure
Given the collector could not run in the page
Then the rule is "Non évaluée" with the detail "La page n'a pas pu être inspectée"

## 5. Non-Functional Requirements (NFRs) & Constraints

- **Performance:** collection plus evaluation of a page with 500 `<script>`/`<style>` elements takes under 20 ms.
- **Accessibility:** no new UI.
