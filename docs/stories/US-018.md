# [US-018] Preview a downloaded font

> **Epic:** PV (see [EPIC-PV-conventions.md](EPIC-PV-conventions.md))
> **Depends on:** "Utiliser des polices standards" (`UseStandardFonts`), US-004 (names); shares the preview dialog with US-015
> **Status:** DONE (automated gates passed, manual browser checks pending; see `docs/reviews/REVIEW-US-015-018.md`)

## 1. User Story Statement

**As an** eco-design auditor,
**I want to** click a downloaded font and read a sample text set in it, then switch to a system font,
**So that** I can show the site owner how close a standard system font would look, and argue for dropping the font download.

## 2. Context & Detailed Description

### Font lines (change to the existing rule)

Today the lines of "Utiliser des polices standards" are full URLs (`https://fonts.gstatic.com/s/roboto/v30/KFOm….woff2`). They become, like the BP2 rules:

- `<shortened name> : <weight>`, for example `roboto-v30-latin-regular.woff2 : 64 ko`;
- the weight is the transferred size, or the decoded size when it came from the cache (transfer size 0), as US-013 does;
- sorted by weight, largest first, then URL; at most 20 lines, then "… et N autres";
- the name is a button opening the font preview.

The grade and the detail ("3 police(s) téléchargée(s) (182 ko) : Roboto, Inter") are **unchanged**. Analyses saved earlier keep their URL lines, as plain text and not clickable.

### Modal content

- The header follows epic §3: the shortened file name, then the full URL.
- **Information:**
  - **Format:** `WOFF2`, `WOFF`, `TTF`, `OTF`, `EOT`; "inconnu" otherwise. It is detected from the file signature, else from the MIME type or extension.
  - **Poids:** the byte length of the file obtained, for example `64 ko`.
- **Sample text,** exactly, with the typographic apostrophe:

  > Tâcher de se vaincre plutôt que la fortune, et changer ses désirs plutôt que l’ordre du monde

  It is followed by "— Voltaire", displayed large enough to judge the glyphs (PO default: 32 px, wrapping inside the modal). The sample cannot be edited (out of scope).
- **Toggle** (radio group, owner decision: technical names), **"Police téléchargée"** selected on open:

  | Label | `font-family` applied to the sample |
  |---|---|
  | Police téléchargée | the downloaded font, loaded from its bytes |
  | Sans-serif | `-apple-system, BlinkMacSystemFont, avenir next, avenir, segoe ui, helvetica neue, Adwaita Sans, Cantarell, Ubuntu, roboto, noto, helvetica, arial, sans-serif` |
  | Serif | `Iowan Old Style, Apple Garamond, Baskerville, Times New Roman, Droid Serif, Times, Source Serif Pro, serif, Apple Color Emoji, Segoe UI Emoji, Segoe UI Symbol` |
  | Mono | `Menlo, Consolas, Monaco, Adwaita Mono, Liberation Mono, Lucida Console, monospace` |

  The three system stacks are applied **exactly** as written: same order and same names. Multi-word names may be quoted in CSS without changing their meaning.
- **Loading the font.**
  - The downloaded font is registered **only in the extension panel**, under a private name, from the file bytes: DevTools content, else the HTTP cache (epic §5).
  - It never affects the inspected page. It is released when the modal closes.
  - It is rendered at normal weight and style.

### States

The states apply to the "Police téléchargée" option only. "Sans-serif", "Serif" and "Mono" are always available.

- `loading`: "Chargement de la police…". The sample is not drawn in a fallback font while it loads.
- `error`:
  - "Police indisponible." when the bytes cannot be obtained;
  - "Ce format de police n'est pas pris en charge par ce navigateur." when the browser refuses the file (EOT, corrupt file).
  - Each has a "Réessayer" button.

## 3. Tech Stack Hints & Scope Constraints

- **In scope:**
  - the new line format with file references;
  - the clickable names;
  - the font modal and toggle;
  - loading a font from bytes in the panel.
- **Out of scope:**
  - reading the family name from the font file;
  - choosing the weight or style;
  - an editable sample;
  - detecting missing glyphs: a subset or icon font shows fallback glyphs, as the browser does;
  - suggesting a replacement font.
- **Persistence:** only the new `lineRefs` of the rule (ARCH-DECISION-017). Font bytes are never stored.
- **Hints for the team lead:**
  - The extension pages CSP has no `font-src` / `default-src`; check that a `FontFace` built from bytes works in Chrome ≥ 103 and Firefox ≥ 109.
  - The font must be unregistered on close, so that fonts don't accumulate in the panel.

## 4. Acceptance Criteria (Gherkin Scenarios)

### Scenario 1: Happy path
Given "Utiliser des polices standards" lists "roboto-v30-latin-regular.woff2 : 64 ko"
When the auditor clicks "roboto-v30-latin-regular.woff2"
Then a modal opens titled with that name and the full URL under it
And it shows "WOFF2" and "64 ko"
And the sample "Tâcher de se vaincre plutôt que la fortune, et changer ses désirs plutôt que l’ordre du monde" with "— Voltaire" is drawn in that font
And "Police téléchargée" is selected

### Scenario 2: Switch to a system stack
Given the font modal is open
When the auditor selects "Serif"
Then the sample is drawn with font-family "Iowan Old Style, Apple Garamond, Baskerville, Times New Roman, Droid Serif, Times, Source Serif Pro, serif, Apple Color Emoji, Segoe UI Emoji, Segoe UI Symbol"
When they select "Police téléchargée" again
Then the sample is drawn in the downloaded font, without reloading it

### Scenario 3: Sans-serif and Mono
Given the font modal is open
When the auditor selects "Sans-serif", then "Mono"
Then the sample uses exactly the Sans-serif stack, then exactly the Mono stack of §2

### Scenario 4: New line format, sorted
Given the page downloaded "a.woff2" (20 kB) and "b.woff2" (98 kB)
When the best practices are evaluated
Then the lines are "b.woff2 : 98 ko" then "a.woff2 : 20 ko"
And the grade and the detail are unchanged

### Scenario 5: Font unavailable, then retry
Given DevTools has no content for the font and the re-download fails
When the auditor opens its preview
Then "Police téléchargée" shows "Police indisponible." and a "Réessayer" button
And "Sans-serif", "Serif" and "Mono" still work

### Scenario 6: Unsupported format
Given the font is an EOT file
When the auditor opens its preview
Then "Police téléchargée" shows "Ce format de police n'est pas pris en charge par ce navigateur."

### Scenario 7: The page is not affected
Given the font modal is open
When the auditor inspects the analysed page
Then no font was added to the analysed page
And after closing the modal, the font is no longer registered in the panel

### Scenario 8: Legacy analysis
Given an analysis saved before this story, whose font lines are full URLs
When the auditor opens it
Then the lines are displayed as before, as plain text, not clickable

### Scenario 9: Close while loading
Given the font is loading
When the auditor closes the modal
Then the late result registers no font

## 5. Non-Functional Requirements (NFRs) & Constraints

- **Performance:** a cached font is drawn immediately when reopened.
- **Accessibility:**
  - native radio inputs, with arrow keys inside the group and a visible group label "Police";
  - the sample is real text: readable, selectable and zoomable;
  - focus management follows epic §2;
  - errors use `role="alert"`.
- **Isolation:** the font is registered only in the panel document and is released on close.
