# [US-016] Preview a flagged video or sound

> **Epic:** PV (see [EPIC-PV-conventions.md](EPIC-PV-conventions.md))
> **Depends on:** US-006, US-014 (rules); shares the preview dialog with US-015
> **Status:** DONE (automated gates passed, manual browser checks pending; see `docs/reviews/REVIEW-US-015-018.md`)

## 1. User Story Statement

**As an** eco-design and accessibility auditor,
**I want to** click the name of a video or sound flagged for missing captions or autoplay, and play it in a modal with its resolution, duration, format and weight,
**So that** I can recognise which media of the page is concerned and assess it (is this muted background video worth its weight? does this clip need captions?).

## 2. Context & Detailed Description

### Where the name is clickable

| Rule | Lines |
|---|---|
| "Fournir une alternative textuelle aux contenus multimédias" (US-006) | "Vidéo `<name>` : ni sous-titres ni libellé" |
| "Éviter la lecture et le chargement automatique des vidéos et des sons" (US-014) | "Vidéo `<name>` : …" and "Son `<name>` : …" |

The prefixes "Vidéo " and "Son " stay plain text; only the name is the button. The epic §1 exclusions apply. In particular, streaming players often use `blob:` sources (MediaSource), and those lines stay plain text.

### Modal content

- The header follows epic §3.
- **Player** (product decision):
  - native `<video controls>` or `<audio controls>`, with `preload="metadata"`;
  - **never autoplays**: playback starts only when the auditor presses play;
  - the source is the media URL, streamed by the player;
  - only the metadata is fetched on open, and the full file is downloaded only if the auditor plays it.
- **Closing the modal pauses playback and stops the download.**
- **Information:**
  - **Résolution** (video only): `1920 × 1080 px`, from the media metadata.
  - **Durée:** `1 min 32 s`, `45 s`, or `2 h 03 min`; "inconnue" for a live stream or before the metadata loads.
  - **Format:** from the recorded MIME type, else the extension: `MP4`, `WebM`, `Ogg`, `MP3`, `M4A`, `WAV`, `AAC`, `FLAC`; "inconnu" otherwise.
  - **Poids téléchargé par la page:** the bytes the page actually transferred for this URL during the analysis (sum over its requests, partial `206` responses included), for example `2 400 ko`. It reads "non téléchargé par la page" when no request for it was recorded (for example `preload="none"`).
- **Display modes** (video only), as in US-015:
  - "Même taille que sur la page" uses the element's CSS box, collected at the latest collection;
  - "Taille réelle" uses the natural size ÷ `devicePixelRatio`;
  - a box that is unknown or 0 × 0 opens in "Taille réelle" with the hint "Vidéo non affichée sur la page".
  - Sounds have no display mode.

### States

- `loading`: "Chargement…" until the metadata is loaded.
- `error`:
  - "Média indisponible." (network error, 404);
  - "Ce format n'est pas lu par ce navigateur." (unsupported source).
  - Each has a "Réessayer" button that reloads the source.

## 3. Tech Stack Hints & Scope Constraints

- **In scope:**
  - clickable names in the two rules;
  - the player modal;
  - the information;
  - the display boxes for the videos of US-006 and US-014.
- **Out of scope:**
  - captions editing or upload;
  - `blob:` / MediaSource streams;
  - players embedded in iframes (YouTube…);
  - thumbnails in the lines;
  - measuring the full file size when the page did not download it.
- **Privacy:**
  - Playing a media downloads it from the panel, outside the measured requests of the inspected tab.
  - The HTTP cache serves it when possible.
  - The README privacy section must say so.
- **Persistence:** the video display boxes are stored with the page, optional. Nothing else is stored.
- **Hints for the team lead:**
  - The extension pages CSP has no `media-src` / `default-src`, so remote media can play; check this in both browsers.
  - The duration and format formatting are pure helpers.

## 4. Acceptance Criteria (Gherkin Scenarios)

### Scenario 1: Happy path: video without captions
Given US-006 lists "Vidéo intro.mp4 : ni sous-titres ni libellé"
And the page downloaded 2 400 ko of intro.mp4, a 1920 × 1080 video of 92 s
When the auditor clicks "intro.mp4"
Then a modal opens titled "intro.mp4" with its full URL
And a paused video player with controls is shown
And it shows "1920 × 1080 px", "1 min 32 s", "MP4" and "2 400 ko"

### Scenario 2: Never autoplays
Given US-014 lists "Vidéo hero.mp4 : lecture automatique" for a video with `autoplay muted loop`
When the auditor opens its preview
Then the player is paused until the auditor presses play

### Scenario 3: Sound from the autoplay rule
Given US-014 lists "Son jingle.mp3 : préchargement complet (preload=\"auto\")"
When the auditor clicks "jingle.mp3"
Then a modal with an audio player opens
And it shows the duration, "MP3" and the weight, with no resolution and no "Taille réelle"

### Scenario 4: Media not downloaded by the page
Given a video with `preload="none"` that the page never requested
When the auditor opens its preview
Then "Poids téléchargé par la page" reads "non téléchargé par la page"

### Scenario 5: Closing stops playback
Given the auditor is playing a video in the modal
When they close the modal
Then playback stops and the media download is cancelled

### Scenario 6: Unsupported format
Given a video in a format the browser cannot play
When the auditor opens its preview
Then the modal shows "Ce format n'est pas lu par ce navigateur." and a "Réessayer" button

### Scenario 7: Media unavailable
Given the media URL answers 404
When the auditor opens its preview
Then the modal shows "Média indisponible." and a "Réessayer" button

### Scenario 8: Streaming source not clickable
Given US-014 lists a video whose source is `blob:https://example.org/…`
When the auditor views the lines
Then its name is plain text, not a button

### Scenario 9: Video not displayed
Given a flagged video whose CSS box is 0 × 0
When the auditor opens its preview
Then the modal opens in "Taille réelle" with the hint "Vidéo non affichée sur la page"

### Scenario 10: Saved analysis
Given a saved analysis whose US-006 lines list "Vidéo intro.mp4"
When the auditor clicks "intro.mp4"
Then the preview plays from the media URL (the HTTP cache when possible)

## 5. Non-Functional Requirements (NFRs) & Constraints

- **Performance:** the modal opens immediately; only metadata is fetched until play.
- **Accessibility:**
  - native controls, so they are keyboard-operable;
  - the player has an accessible name such as "Aperçu de intro.mp4";
  - focus management follows epic §2;
  - loading uses `role="status"` and errors `role="alert"`.
- **Sobriety:** no autoplay, `preload="metadata"`, and the download is stopped on close.
